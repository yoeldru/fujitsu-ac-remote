# שלט פוג'יטסו – שליטה מלאה דרך Broadlink RM4 mini

אפליקציית אנדרואיד שמדברת **ישירות** עם ה-RM4 mini ברשת הביתית (ללא הענן של Broadlink),
ומרכיבה בעצמה את קוד ה-IR המלא של מזגן פוג'יטסו – כולל תריסים.

## מה יש
- **כמה מזגנים**, לכל אחד RM4 משלו, שם, תזמונים וכפתורים נלמדים משלו; מעבר ביניהם בלחיצה
- **קבוצות מזגנים** (למשל "סלון ומטבח") – שליטה, מועדפים ותזמונים לכל הקבוצה יחד
- קוד שלט A/B/C/D – להפרדה בין שני מזגנים זהים באותו חדר
- הדלקה/כיבוי, טמפרטורה 16–30, מצב (אוטו/קירור/ייבוש/מאוורר/חימום), מאוורר (אוטו/חזק/בינוני/חלש/שקט)
- **תריסים**: נדנוד אוטומטי (קבוע / למעלה-למטה / לצדדים / הכל) + כיוון ידני צעד-אחר-צעד, אנכי ואופקי
- אקונומי ו"עוצמתי"
- מועדפים (שמירת מצב בלחיצה)
- תזמונים לפי שעה וימים + טיימר כיבוי מהיר
- לימוד כל כפתור מהשלט המקורי (גיבוי)
- **גיבוי והעברת הגדרות** לטלפון אחר – שליחה בוואטסאפ, קובץ, או הדבקת קוד; גיבוי אוטומטי של גוגל
- **עדכונים מתוך האפליקציה** – כרטיס "עדכון זמין" + נקודה אדומה; הורדה והתקנה בלחיצה
- עברית מלאה, מצב כהה

## בנייה
1. צור ריפו חדש ב-GitHub (למשל `fujitsu-ac-remote`) והעלה אליו את כל הקבצים.
2. GitHub Actions בונה APK אוטומטית בכל דחיפה ל-`main`.
3. ה-APK מתפרסם ב-Releases תחת `latest` בשם `fujitsu-remote.apk`:
   `https://github.com/yoeldru/fujitsu-ac-remote/releases/download/latest/fujitsu-remote.apk`

## הגדרה ראשונה
**דרך מומלצת – בלי אפליקציית Broadlink:** הגדרות ← "הגדרת שלט חדש". עושים ריסט לשלט (נורית מהבהבת לאט), מזינים את פרטי רשת ה-2.4GHz, והאפליקציה מחברת את השלט לרשת ומשייכת אותו למזגן.

**שלט שכבר מחובר דרך Broadlink:**
1. באפליקציית Broadlink: המכשיר ← הגדרות ← **נעילת מכשיר (Lock device) = כבוי**. בלי זה אין שליטה מקומית.
2. מומלץ לקבע ל-RM4 כתובת IP קבועה בנתב.
3. באפליקציה: הגדרות ← "חפש ברשת הביתית" (או הזנת IP) ← "בדיקה: הדלק 24° קירור".
4. אם המזגן לא מגיב – בדוק את דגם השלט המקורי (כתוב בגבו) ובחר אותו בהגדרות.

## מגבלות
- שלט IR הוא חד-כיווני: האפליקציה לא יודעת אם מישהו שינה משהו בשלט הרגיל.
- תזמונים רצים מהטלפון – הוא צריך להיות בבית ועל ה-Wi-Fi בשעת התזמון.
- שליטה מחוץ לבית דורשת "גשר" (שלב הבא).

## מבנה הקוד
- `core/FujitsuIr.java` – מקודד פרוטוקול פוג'יטסו + המרה לפורמט Broadlink
- `core/BroadlinkDevice.java` – פרוטוקול Broadlink (גילוי, אימות AES, שליחה, לימוד)
- שאר הקבצים – ממשק, תזמונים ושמירה

## עדכונים
כל דחיפה ל-`main` בונה גרסה חדשה (מספר הגרסה = מספר ה-build). האפליקציה בודקת את ה-Release `latest`,
מציגה "עדכון זמין" ומורידה ומתקינה בעצמה. שורת הנושא של ה-commit מוצגת כ"מה חדש".
בעדכון הראשון אנדרואיד יבקש פעם אחת הרשאת "התקנה מהמקור הזה".

החתימה (`app/fujiac.keystore`) קבועה כדי שעדכונים יותקנו מעל הגרסה הקיימת.
